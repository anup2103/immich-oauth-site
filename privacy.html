Privacy Policy

Last updated: October 18, 2026

Immich Homelab Backup is a private, non-commercial application for backing up the owner's self-hosted photo library.

Google Drive Access

The application uses Google Drive API access to create, read and manage backup files in the owner's Google Drive.

Data Security

Backup contents are encrypted locally using Restic before being uploaded. Google OAuth credentials are stored locally.

Data Sharing

The application does not sell personal data or intentionally share backup contents with third parties.

Data Retention

Backups are retained according to the owner's configured retention policy and can be deleted by the owner.
